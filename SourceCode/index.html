How conversion works

Subset construction: begin with the singleton start set. For each reachable subset and input symbol, union the destinations of its NFA states. Each new subset becomes a DFA state. A DFA state is accepting when its subset contains at least one NFA accepting state.
The empty subset is retained when reached, so every generated DFA state has a transition for each alphabet symbol.
